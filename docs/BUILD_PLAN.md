# Plan de construcción auditado

## Fase 0 — archivos y contratos
Se crean todos los archivos, contratos, migraciones, Edge Functions, documentación y base Android sin afirmar que estén desplegados.

## Fase 1 — fundación verificable
Auth, perfiles, materias, RLS, navegación y configuración pública de Supabase.

## Fase 2 — chat
Conversaciones, mensajes, agentes conceptuales, memoria y orquestación backend.

## Fase 3 — RAG
Storage privado, procesamiento, extracción, chunking, embeddings 1536, retrieval, citas y aislamiento.

## Fase 4 — producto educativo
Evaluaciones, notas 1–20, APA configurable, feed, recomendaciones y analítica.

## Fase 5 — créditos y Pro
Contabilidad idempotente, reglas configurables, límites y pagos solo mediante webhook verificado.

## Fase 6 — validación
Migraciones en Supabase, pruebas RLS, pruebas de Edge Functions, compilación Android, CI, Pull Request y APK.

**Regla:** un archivo existente no equivale a una capacidad terminada. Cada fase requiere evidencia de ejecución.
