# Pruebas pendientes

Esta carpeta define la matriz que debe ejecutarse antes de declarar el MVP:

- Auth y sesión expirada.
- RLS entre dos usuarios y dos materias.
- Storage privado.
- Créditos atómicos e idempotencia.
- Aislamiento de chunks.
- Prompt injection en documentos.
- Citas y límites de contexto.
- Compilación e instalación Android 11+.
